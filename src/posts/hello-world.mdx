# Hello World

Welcome to the blog! This post is written in **MDX**, which means you can use standard Markdown
as well as embed React components.

## What is MDX?

MDX lets you write JSX directly inside Markdown files. That means you can import and use React
components alongside your prose content.

## Code Example

```ts
function greet(name: string): string {
  return `Hello, ${name}!`
}

console.log(greet('World'))
```
